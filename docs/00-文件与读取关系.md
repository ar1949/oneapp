# 00 文件与读取关系

谁读哪个文件、读哪些字段、读不到怎么办。**改字段名必须三端同改**——清单、启动器、下载器是一套契约，单边改名会让对面静默不动。

## 一张表

| 读取方 | 读哪里 | 只取哪些字段 | 拿不到时怎么办 |
|---|---|---|---|
| 启动器 | `res/latest.json` | `schema` / `channel` / `client_version` / `min_version` / `install_order` / `assets[]` 里 **`kind == "patch"` 的那几条** | 三条源都失败 → 保留本地版本，界面提示"检查更新失败"，**不推进、不删除任何文件** |
| 启动器（自更新） | `app/launcher/latest.json` | `version` / `size` / `sha256` / `url` | 同上下载失败则跳过自更新，不影响主流程 |
| 下载器 | `res/latest.json` | **全部 kind**（`baseline` / `shell` / `patch`）+ `install_order` | 清单 404 或 `schema != 1` → 直接报错退出，**不进入下载** |
| 下载器（anondrop 源） | `res/anondrop-map.json` | `{文件名: 直链}`，按 `parts[].name` 查表 | 查不到就跳过该源，其余源照跑 |
| 下载器（逐卷） | `parts[]` | `index` / `name` / `size` / `sha256` | 缺 `sha256` → 该卷判为不可信，**拒收** |
| 安卓壳 | `app/latest.json` | `version_code` / `version_name` / `apk` / `size` / `sha256` | 与本清单无关，独立链路 |

## 启动器只认 patch，这是硬规则

启动器体积只有 8MB 量级，它**不**下载 `baseline`（15GB）、也**不**下载 `shell`（自己替换自己会崩）。所以：

```
for id in install_order:
    a = assets[id]
    if a.kind != "patch":        # baseline / shell 一律跳过
        continue
    if a.from != local_version:  # 补丁链对不上，跳过（由下载器整包升）
        continue
    下载 a.parts -> 校验 sha256 -> 解压覆盖
```

`install_order` 里的 `baseline` / `shell` 对启动器是"看得见但不处理"的条目，保留它们是为了让下载器和启动器**共用同一份清单**，不必维护两个文件。

## 下载器读全部，顺序即覆盖顺序

```
for id in install_order:          # 数组顺序 = 安装顺序
    下载该 asset 所有 parts
    逐卷校验 parts[].sha256        # 任一卷不符 -> 该卷重下，重下仍不符 -> 整体失败
    拼接/解压
    覆盖到目标目录                 # 后项覆盖前项
```

顺序约定固定为：

1. `baseline-*` —— 打底，整包铺开
2. `shell-*` —— 覆盖旧的壳程序
3. `patch-*` —— 最后叠补丁，补丁内容优先级最高

所以补丁里带同名文件时**一定是补丁赢**。反过来说，补丁里不要放"整包才该有的目录结构"，只放差异文件。

## 为什么清单是唯一入口

- 启动器、下载器读同一个 `res/latest.json`，发版只改一个文件；
- 渠道地址不写在程序里，全在清单的 `sources[]`，换线路不用重新发包；
- 校验值也不写在程序里，`parts[].sha256` 是唯一依据。

## 目录里各文件的作用

| 路径 | 作用 | 谁写 |
|---|---|---|
| `res/latest.json` | 统一资源清单，程序读取入口 | `make_res_manifest.py` 生成，不手改 |
| `res/anondrop-map.json` | 单文件直链平表，仅 `type=anondrop` 使用 | 同上，自动生成 |
| `app/latest.json` | 安卓壳自身版本 | 壳的发布流程 |
| `app/launcher/latest.json` | 启动器自身版本（含 `url`） | 启动器发布流程 |
| `app/launcher/ONETAPLauncher.bin` | 启动器二进制 | 启动器发布流程 |
| `app/downloader/latest.json` | 下载器自身版本（目录按需建立） | 下载器发布流程 |
| `docs/` | 人看，程序不读 | 手写 |
