# 维护说明

## 客户端取配置的顺序

```
外壳 ──读──> res/latest.json ──> 各资源的版本 / 大小 / sha256
                              └──> res/sources.enc（加密配置，解密后覆盖地址）
```

## 版本规则

- 内容版本：`1.0.0` 起，补丁递增 `1.0.1`、`1.0.2`…
- 外壳版本：`1.0.0` 起，独立递增，与内容版本无关
- release tag：`v<内容版本>`，仅作容器标签

## 发版要动的文件

1. `res/latest.json` — 版本号 / 文件列表 / 时间 / 说明
2. `app/*/latest.json` — 外壳的 version / size / sha256
3. `res/sources.enc` — 地址有变动时

## 注意

- 任何 `size` / `sha256` 与实际文件不符，客户端会直接拒绝，不会装坏。
- 加密配置改动后需整体重新生成，不要手工拼接。
