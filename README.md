# oneapp

按版本切分的静态文件分发仓库。同一份内容分卷存放、多通道同步，附清单与逐卷校验值。

本仓库不托管运行逻辑，只做两件事：**存文件**（分卷、壳、增量补丁）和**发清单**（哪一版、哪些文件、从哪些地址取、校验值是多少）。

## 目录

| 路径 | 内容 |
|---|---|
| `README.md` | 本文件 |
| `docs/` | 约定与流程，人工阅读，程序不读 |
| `app/` | 壳程序与其自身版本清单，按子目录分 |
| `res/` | 统一资源清单，程序读取的唯一入口 |

## 清单

`res/latest.json` 是唯一入口。读它的程序有两个，取用范围不同：

| 读取方 | 取哪些 |
|---|---|
| 更新器 | 只取 `kind == "patch"` 的条目，按 `install_order` 顺序叠加 |
| 安装器 | 取全部条目，按 `install_order` 顺序下载、校验、解压、覆盖 |

顶层字段：

| 字段 | 说明 |
|---|---|
| `schema` | 固定 `1`，结构变更时递增 |
| `channel` | 渠道名，当前 `stable` |
| `client_version` | 本次发布的版本 |
| `min_version` | 低于它的旧版必须整包重装，不接受增量 |
| `released` | 发布时间，`YYYY-MM-DD HH:MM:SS` |
| `notes` | 发布说明，纯文本 |
| `install_order` | 条目 id 数组，**数组顺序即安装顺序**，后项覆盖前项 |
| `assets` | 条目数组，见下 |

`assets[]` 的 `kind` 只有三种：

| `kind` | 含义 | 结构 |
|---|---|---|
| `baseline` | 完整内容包 | 按 `parts[]` 分卷，每卷有独立的 `sha256` |
| `shell` | 壳程序 | 单文件，`parts` 只有一条 |
| `patch` | 增量补丁 | 用 `from` / `to` 描述两端版本，单文件 |

`sources[].type` 只有四种：`fj`（网盘）、`ghproxy`（转发）、`github`（直连）、`anondrop`（备用直链）。`weight` 是 0–100 的相对权重，用于分配下载并发，只比大小、不做归一化。

`res/anondrop-map.json` 是 `{文件名: 直链}` 的平表，只有 `type=anondrop` 的源会查它。

## 版本号

| 对象 | 形如 | 规则 |
|---|---|---|
| 主内容包 | `1.0.YYYYMMDD.N` | 日期 + 当日序号 |
| 壳 | `1.0.X` | 各自独立递增，与日期无关 |
| 补丁 | `from → to` | 无独立版本号 |

**三套版本号互不比较大小。** 判定"要不要更新"只比 `sha256`：内容变了哈希必变，内容没变哈希必同，跨命名空间也成立。拿 `1.0.36` 和 `1.0.20261102.2` 做数值比较会得出相反的错误结论，详见 `docs/01-版本号规则.md`。

## 校验

- 逐卷：`parts[].sha256`，一卷不符则该卷重下，重下仍不符即整体失败。
- 整包：`total_sha256`，解压前对完整内容算一次。
- 缺 `sha256` 的条目视为不可信，直接拒收。
- 校验不通过时**不安装、不提示哈希细节**，只保留上一份可用状态。

## 下载通道

| 通道 | 单连接 | 4 并发 | Range | `weight` |
|---|---|---|---|---|
| 网盘 CDN | 1.5 MB/s | 6.2 MB/s | 支持 | 100 |
| 转发 | 0.4–2 MB/s 波动 | ~3.9 MB/s | 支持 | 60 |
| 直连 | 39 KB/s | — | 支持 | 40 |
| 备用直链 | 19 KB/s | — | 不支持 | 5 |

数值为本机实测基线，环境变化后需重测；各通道的失败形态与重测方法见 `docs/03-资源通道与测速基线.md`。

## 约定

- **已发布的 tag 不改指向。** 内容要变就发新版本号。tag 被移动会导致 CDN 缓存与校验值长期不一致。
- **已发布的文件名不改。** 改名等于让所有已发出的清单 404。
- **写清单前先 `--dry-run`。** 完整输出看过一遍，再决定是否发布。
- **`res/` 不手改。** 由生成器产出，手改会在下次生成时被覆盖，且容易漏掉某个 `sha256`。
